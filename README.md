# Roster Parser

Import my church roster as a .pdf and add to my Google calendar

## Prerequisites

ics

```bash
pip install ics
```

pdfplumber
```bash
pip install pdfplumber
```
zoneinfo
```bash
pip install backports.zoneinfo
```
